# Diagram pipeline

This directory holds the source → render pipeline that produces the
Excalidraw diagrams used in `README.html` and other docs.

## What's here

| Path | Role |
|------|------|
| `excalidraw/*.excalidraw` | Hand-authored Excalidraw JSON (the source of truth for diagram layout) |
| `png/*.png` | Rendered PNGs (regenerated by `render_local.py`; committed for the HTML README) |
| `render_local.py` | Headless-Chromium renderer — bundles `@excalidraw/excalidraw` with esbuild and serves the bundle + assets via a local HTTP server |
| `build_readme_html.py` | `README.md` → `README.html` with the four diagram substitutions |
| `_importmap.py` | Helper: scan a JS bundle for bare specifiers, resolve each via its `package.json`, emit an importmap (legacy; not used by the renderer anymore) |

## Render a diagram

```bash
# Render a single .excalidraw to PNG
uv run --with playwright python diagrams/render_local.py \
    diagrams/excalidraw/01-3-layer-convergence.excalidraw \
    --output diagrams/png/01-3-layer-convergence.png --width 1800
```

The renderer pre-bundles Excalidraw and all transitive deps (react, jotai,
roughjs, …) into a single ESM file with esbuild so the headless browser only
fetches one script. The bundle is cached at
`/tmp/dark-factory-excalidraw.bundle.js` and rebuilt only when the Excalidraw
entry mtime changes.

The companion assets (fonts, locales) are copied to
`/tmp/dark-factory-excalidraw-assets/` so the Excalidraw runtime can fetch
them at `/locales/…` and `/fonts/…`.

## Build the HTML README

```bash
uv run python diagrams/build_readme_html.py
```

This reads `README.md` from the repo root, swaps the four ASCII / Mermaid
diagram blocks for the corresponding PNGs, and writes `README.html`. The
output uses a cream + brand-teal design palette and a sticky table of
contents. The exact tokens are baked into `build_readme_html.py`.

## Color contract

All colors used in the `.excalidraw` files come from the shared vocabulary
documented in [`../docs/diagram-color-semantics.md`](../docs/diagram-color-semantics.md).
The Excalidraw skill at `~/.claude/skills/excalidraw-diagram/references/color-palette.md`
is a mirror of that table — if you change a color in either, update both.
