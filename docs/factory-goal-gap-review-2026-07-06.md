## 4. Major gaps (reliability) and minor

**Major:**
- No per-tick error isolation: one gh 403/timeout kills the daemon process (main.rs:277→exit(1)); no ETag cache, no backoff, 10s ticks maximize rate-limit exposure; 8 prior daemon deaths visible in the log.
- Shell vs Rust intake divergence: shell has no author permission gate, misses directly-labeled PRs, un-parks what Rust parks; roadmap "paths aligned" claim is false.
- Shell lane spawn-before-record inverts the Rust daemon's correct ordering → possible untracked/duplicate coder sessions.
- recover-held churn (unconditionally requeues deliberate parks) then silently freezes at attempt≥10 with no escalation.
- Daemon skeptic gate is ungrounded (bead id + PR number only, wrong cwd, no diff/SHA binding) — gate 7 verdicts are not real behavioral checks.
- End-to-end never proven: smoke evidence used /tmp DB + br shim and skipped AO spawn; smoke issue #8164 still OPEN; completed work never reconciled to GH issues (loop open at both ends); the one autonomous READY ever emitted was a false positive (fix landed, unvalidated).
- Cutover exit criteria: 0/10 met by the repo's own scorecard (all real-adapter tests #[ignore]; single-writer violated by design).

**Minor:** offline bead-file fail-safe is a read-only stub (roadmap overclaims "full offline operation"); DIRECT_PATH/PR_LESS spec-only and its cited gap-analysis doc (`docs/auto_factory_spec_gap_analysis.md`) was never committed — roadmap docs repeatedly assert artifacts that aren't on main.

## 5. What already works

- **Intake is genuinely solid**: label→bead with external_ref idempotency in both lanes; Rust adds write-tier author authorization, PR-label coverage, 300s permission cache, beads-only (GH-less) intake.
- **The Rust daemon poll loop is real and live**: 10s ticks, structured JSONL telemetry, and one full happy path executed on 2026-07-06 (intake → route → real `ao spawn` → PR #8177/#8178 opened).

- **The factory has produced merged work**: 4 worldarchitect.ai PRs it drove merged on 2026-07-06 — with a human clicking merge.

**Bottom line:** the skeleton (state machine, telemetry, safety caps, intake) is Level-5-shaped and better-engineered than the findings' tone suggests, but the loop is severed in four places — recovery, /er, /code-standards+/zfc, and scheduling — and until those land, "tag it with factory" produces a bead that waits forever in HUMAN_HELD.
