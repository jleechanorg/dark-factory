## What I patched in dark-factory

### `prompts/slim/plan.md`
Added 5 hard sections after the existing file-ownership matrix:

- **Hard cap 3-4 lanes per wave** (with reference to the lvl: refactor
  67-PR chain as the counter-example).
- **Hard cap 2 active writers per file** (1 preferred); if two lanes must
  touch the same file, serialize and stop.
- **No pre-emptive PRs gated on a not-yet-merged PR.** Dependent lanes
  must be parked until the gate PR merges.
- **Mandatory global kill switch** in the spec:
  - idle >20 min with head SHA unmoved → kill
  - file-ownership matrix drift detected → stop and renegotiate
  - 2 ghost fixers on the same lane → halt, fall back to one owner
- **Pre-flight commands** the spec MUST paste output of, before spawning
  workers: `git diff --name-only`, `git merge-tree --write-tree`,
  `uniq -c` writer count, `gh pr view` gate-PR state check.

### `prompts/catalog/plan.md`
Same 5 sections added (slimmer wording but same constraints). The
catalog version is the older prompt and is missing the
`explore-findings.md` integration; that's pre-existing and out of scope
for this audit.
