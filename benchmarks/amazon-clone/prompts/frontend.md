# Frontend Task

Implement the frontend application for `benchmarks/amazon-clone/spec.md`.

## Required Work

- Build route-backed views for all public frontend view requirements.
- Make the first screen the usable storefront.
- Implement catalog, search, filters, product detail, cart, wishlist, auth,
  address book, checkout, confirmation, order history, reviews, seller console,
  admin moderation, notifications, and diagnostics.
- Read and write through the backend API, not browser-only constants.
- Preserve meaningful state across refresh and URL navigation.
- Support desktop, laptop, tablet, and mobile widths.
- Include accessible labels, visible focus states, keyboard paths, and
  aria-live updates for cart and checkout changes.
- Add browser tests for a complete checkout and order-history flow.

Do not inspect sealed holdouts or hidden evaluator paths.
