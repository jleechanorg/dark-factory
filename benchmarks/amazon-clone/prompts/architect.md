# Architecture Task

Design the application architecture for `benchmarks/amazon-clone/spec.md`.

## Output

Specify:

- Frontend framework, routes, component boundaries, state model, and API client.
- Backend runtime, route groups, validation layers, and domain modules.
- Firestore repository modules and transaction boundaries.
- Auth/session model for local benchmark use.
- Seed/reset design.
- Test layout for unit, integration, browser, rules, and source-size checks.

Keep the design implementable in one repository with the launch commands from
the spec.
