# Hello Feature

## Goal

Smoke-test the Dark Factory by adding a `hello()` function to `impl/greet.py`
that returns the string `"Hello, world!"`.

## Requirements

1. Module `impl/greet.py` exists.
2. `hello()` takes no arguments and returns exactly `Hello, world!`.

## Non-Goals

- Argument handling
- Internationalization
- CLI wrapping
